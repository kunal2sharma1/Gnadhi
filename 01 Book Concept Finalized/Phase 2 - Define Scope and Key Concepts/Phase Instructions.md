# Phase 2 — Define Scope and Key Concepts

## Objective
Turn the raw concept into clearly defined terms and boundaries so that later research does not suffer from vague language or hidden assumptions.

## What this phase must accomplish
Define the book’s subject, time range, intended scope, key terms, major distinctions, and areas that require evidence before they can be presented as historical conclusions.

Particular attention must be given to the phrases “the ideology,” “trying to kill Gandhi,” “still trying to kill him,” and “still failing.” The wording must be precise enough to avoid unfairly treating a diverse political or ideological field as a single actor.

## Sub-phases

### Sub-phase 2.1 — Scope Definition
**Assigned to:** ChatGPT

**Work:** Use the completed Phase 1 files to define the subject boundaries, time boundaries, geographic boundaries, and topics that are outside the book’s scope.

**Output:** `02.1 Scope Definition.md`

### Sub-phase 2.2 — Key Terms and Historical Risk Check
**Assigned to:** Claude

**Work:** Read the completed Phase 1 files and identify ambiguous, politically loaded, historically risky, or potentially misleading terms. Explain which phrases need careful definition and which claims must be treated as hypotheses pending research. Do not write the book and do not assume the author’s thesis is correct.

**Output:** `02.2 Key Terms and Risk Review.md`

### Sub-phase 2.3 — Scope Consolidation
**Assigned to:** ChatGPT

**Work:** Combine the scope definition with Claude’s risk review. Produce the working definitions and boundaries that will guide the rest of the project.

**Output:** `02.3 Working Definitions and Boundaries.md`

## Agent instructions
Every agent must read the Phase 1 outputs before working. Claude must clearly separate historical cautions from established facts. ChatGPT must not silently remove an authorial idea merely because it is controversial; it should identify what requires later evidence.

## Completion condition
The book’s subject and key terms are sufficiently precise that different agents would interpret the project in substantially the same way.
