# Phase 2 — Define Scope and Key Concepts

## Objective
Turn the raw concept into precise, usable boundaries and definitions so later research does not depend on vague or politically loaded language.

## What this phase must accomplish
Define what the book will investigate, what it will not investigate, the broad time and subject boundaries, and the meaning of the major phrases in the original concept.

Special attention must be given to “the ideology,” “trying to kill Gandhi,” “still trying to kill him,” and “still failing.” These are working phrases from the author’s concept, not established historical conclusions. They must be tested and defined carefully.

## Sub-phases

### Sub-phase 2.1 — Define Book Scope
**Assigned to:** ChatGPT Go execution account

**Work:** Use the completed Phase 1 outputs supplied in the context package. Define subject boundaries, time boundaries, geographic boundaries, major inclusions, major exclusions, and the questions the book will intentionally leave outside its scope.

**Output:** `02.1 Scope Definition.md`

### Sub-phase 2.2 — Historical and Language Risk Review
**Assigned to:** ChatGPT Go execution account — Critical Review role

**Work:** Read the Phase 1 outputs and the 02.1 scope definition. Identify ambiguous terminology, politically loaded language, unsupported assumptions, possible historical conflations, and statements that could unfairly treat a diverse ideological field as one actor. State what must remain hypotheses until research establishes it.

**Output:** `02.2 Key Terms and Risk Review.md`

### Sub-phase 2.3 — Working Definitions and Boundaries
**Assigned to:** This ChatGPT account — Product Manager

**Work:** Review the previous outputs, resolve conflicts, preserve the author’s intent where defensible, and create the official working definitions and boundaries for the project.

**Output:** `02.3 Working Definitions and Boundaries.md`

## Execution rule for all sub-phases
The Product Manager must create a self-contained context package for each execution account. The agent must not be expected to find or remember missing material from an earlier conversation.

## Handoff rule
Every output must clearly separate:
- established project decisions
- author assumptions
- historical hypotheses
- unresolved questions
- risks requiring later evidence

## Completion condition
The project has clear working boundaries and definitions that another agent can apply without guessing what the book means.

## Next phase dependency
Phase 3 must use the approved working definitions and boundaries together with the accepted Phase 1 material.
