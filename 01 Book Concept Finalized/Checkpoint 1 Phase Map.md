# Checkpoint 1 — Phase Map

## Phase 1 — Research Planning and Author Input
Prepare the author's starting concept and define the research questions that matter.

## Phase 2 — Seven Claude Research Packets
Run seven narrow, independent Claude research assignments before the main GPT analysis.

## Phase 3 — Research Consolidation and Context Pack
Compare the seven research packets and create one reliable context pack for the GPT workers.

## Phase 4 — Parallel GPT Deep Work
Run three ChatGPT Go workers simultaneously on three different reasoning tracks for an extended work cycle. Continue prompts deepen the same work instead of repeating it.

## Phase 5 — Cross-Worker Review and Targeted Gap Research
Compare the three workers, identify material gaps, commission only the research needed to close those gaps, and run a reconciliation round.

## Phase 6 — Final Concept Synthesis
Create the strongest evidence-aware version of the concept, central question, working thesis, boundaries, and evidence requirements.

## Phase 7 — Checkpoint Completion Review and Next Checkpoint Brief
Close the checkpoint, record lessons and unresolved questions, and define only the high-level objective of Checkpoint 2.

## Flow
Phase 1 → Phase 2 → Phase 3 → Phase 4 → Phase 5 → Phase 6 → Phase 7

## Parallel points
Phase 2: all seven Claude assignments run independently.

Phase 4: all three GPT workers run simultaneously.

Phase 5: reconciliation work can again run across the three GPT workers in parallel.

## Control point
This ChatGPT account acts as Product Manager throughout the checkpoint. It prepares assignments, controls handoffs, compares outputs, and determines when a phase is complete.
