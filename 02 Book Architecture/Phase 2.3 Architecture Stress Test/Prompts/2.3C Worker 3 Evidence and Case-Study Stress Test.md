## Core Question
Can the architecture actually prove its intended historical claims?

Keep separate:
- what happened;
- what actors said happened;
- what institutions concluded;
- what later scholars inferred;
- what the author wants to argue.

Do not treat these as interchangeable.

# 4. Assassination Evidence Audit

- Godse statements;

# 5. Immediate-Aftermath Evidence Audit
Determine what can responsibly be claimed about:
- Nehru's 30 January broadcast;
- Cabinet/government resolutions;
- mourning;
- funeral rituals;
- public reaction;
- immediate state action against communal organisations;
- emergence of Gandhi/Godse counter-memory.

Separate fact of response → stated meaning → inferred political effect.

# 6. State Canonisation vs Assassination Effect
Separate the possible causes of Gandhi's posthumous status:
- pre-existing fame;
- Congress legitimacy needs;
- Indian nation-building;
- international reputation;
- state commemoration;
- Gandhi's institutions;
- violent assassination;
- martyr framing.

Identify what evidence is needed before claiming assassination materially changed later canonisation.

# 7. Post-1948 Case-Study Audit
Evaluate candidates under:
- state/public memory;
- Gandhian movements;
- Ambedkarite criticism;
- left/socialist criticism;
- Hindu-nationalist criticism or appropriation;
- education/textbooks;
- memorial/heritage politics;
- Godse counter-memory;
- political speeches/programmes using Gandhi.

For each ask:
1. Is actor identifiable?
2. Is action identifiable?
3. Is the relevant Gandhi identifiable?
4. Is a mechanism documented?
5. Is primary evidence available?
6. Is there a serious counterinterpretation?
7. Does the case materially change the argument?
8. Is another case better?

# 8. Case-Study Scoring
Score each candidate 1–5 on:
- historical importance;
- mechanism relevance;
- primary-source strength;
- scholarly support;
- counterargument quality;
- distinctiveness;
- causal usefulness;
- manuscript value;
- presentism risk, where 5 = low risk.

Classify: ESSENTIAL / STRONGLY RECOMMENDED / OPTIONAL / REJECT.

# 9. Modern Case Classification Test
Classify each modern case as:
CONTINUITY / INHERITANCE / APPROPRIATION / COUNTER-MEMORY / RECURRENCE / ANALOGY / UNRELATED.

Define evidence required for every label. Never classify similarity as continuity.

# 10. Evidence-Burden by Chapter
For every chapter in the master architecture determine:
- minimum primary-source package;
- minimum secondary-source package;
- major claim dependent on the evidence;
- strongest evidence gap;
- chapter failure condition.

# 11. Source Failure Test
Identify what happens if:
- a key archival document cannot be located;
- a quotation proves disputed;
- a legal record is narrower than expected;
- later inquiry contradicts an earlier finding;
- scholarship is split;
- intent cannot be demonstrated;
- a case is symbolic but not demonstrably political.

For each decide SURVIVE WITH REVISION / SURVIVE AS CONTEXT / REPLACE / REMOVE.

# 12. Evidence-Argument Errors
Identify architecture assumptions equivalent to:
- event = meaning;
- quotation = motive;
- membership = responsibility;
- symbolic use = substantive inheritance;
- criticism = destruction;
- similarity = continuity;
- state commemoration = public consensus;
- fringe counter-memory = mainstream position.

Give exact corrections.

# 13. Counterevidence Requirement
Identify where the manuscript must include inconvenient evidence such as:
- serious criticism of Gandhi;
- state canonisation with causes beyond assassination;
- sincere appropriation;
- evidence limiting organisational responsibility;
- evidence against modern continuity;
- contradictions within Gandhian practice.

# 14. Case-Study Overload Test
Determine whether too many mechanisms/cases are being forced into the book. Recommend CORE / SUPPORTING / OPTIONAL / REMOVED.

# 15. Evidence-Based Replacement
If a chapter or mechanism is unsupported, propose the strongest evidence-supported replacement rather than only rejecting it.

# 16. Final Verdict
Choose exactly one:
A. Evidence architecture is strong.
B. Strong but requires targeted case changes.
C. Major evidence redesign required.
D. Architecture cannot currently be supported.

If B or C, specify exact changes by Part/chapter. If D, propose a replacement evidence architecture.
