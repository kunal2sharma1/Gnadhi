# Phase 2.3 Worker Commands

These are the only commands that need to be pasted into the three ChatGPT worker chats.

The detailed task instructions are stored in GitHub so the worker can read the exact current version from the repository instead of relying on a large pasted prompt.

## Worker 1 Command

```text
You are GPT Worker 1 for THE FINAL WALK OF GLORY.

Work at full available reasoning capacity.

First read and follow this task packet from the repository:

`02 Book Architecture/Phase 2.3 Architecture Stress Test/Prompts/2.3A Worker 1 Historical Integrity Stress Test.md`

Follow that file exactly.

Important execution rules:
- Read all prerequisite files specified inside the task packet.
- Work independently. Do not read or depend on Worker 2 or Worker 3 outputs.
- Do the full historical stress test, not a summary.
- Use the full available context and reasoning capacity.
- Write the required output directly into GitHub.
- Commit the output.
- Verify the output file exists and contains the completed work.
- ONLY AFTER successful verification, delete the task packet you just read:
  `02 Book Architecture/Phase 2.3 Architecture Stress Test/Prompts/2.3A Worker 1 Historical Integrity Stress Test.md`
- Commit that deletion separately.
- Do not delete any other prompt, worker output, master architecture file, or project file.

Do not return the full report in chat. Return only a brief completion confirmation and the committed output path after all repository actions are complete.
```
